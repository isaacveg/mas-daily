- **作者备注**：36 pages, four figures
- **摘要（中文·Agent翻译）**：我们研究一类策略性假设检验问题：委托方希望在相互竞争的智能体之间分配资源，而这些智能体掌握着可能与委托方目标相关的数据或数据生成机制。每个智能体可支付参与成本以加入一份统计合约，此时它从私有分布生成数据，并依据一个预先确定（且公开已知）的机制获得分配。每个智能体要么是「零假设」的，要么是「非零假设」的，委托方的目标是设计合约，使分配尽量限于前者，同时最大化与后者的交易。我们借助 e-value 定义「连续闭包」（continuous-closure），这是一组分配方案，它使零假设智能体在期望上无法获利，并在任意相依性下为一般损失函数提供事后风险控制。当损失为分配给零假设智能体的资源比例时，该区域允许多项式时间的线性优化。我们还给出显式、可解释的闭式近似，并从非零假设智能体的视角分析参与行为，给出加入合约可获利的条件。最后，我们把框架扩展到支持智能体的在线到达，此时委托方必须做出不可撤销的即时决策，并提供一种在该设定下给出时间一致误差控制的方法。

<summary>摘要（英文原文）</summary>

We study a class of strategic hypothesis testing problems in which a principal aims to allocate resources among competing agents who possess data or data-generating mechanisms that may be relevant to the principal's goals. Each agent can pay a participation cost to opt into a statistical contract, in which case they generate data from a private distribution and receive an allocation based on a predetermined (and publicly known) mechanism. Each agent is either "null" or "non-null" and the principal's goal is to design the contract to limit the allocation to the former while maximizing transactions with the latter. Using e-values, we define a "continuous-closure," a set of allocations which prevents null agents from profiting in expectation and provides post-hoc risk control for general loss functions under arbitrary dependence. When the loss is the fraction of resources allocated to null agents, the region admits polynomial-time linear optimization. We also give explicit, interpretable closed-form approximations, and we analyze participation from a non-null agent's perspective, giving conditions under which entry into the contract is profitable. Finally, we extend the framework to support online arrival of the agents, in which case the principal has to make irrevocable on-the-fly decisions, and provide a method which gives time-uniform error-control in this setting.

<summary>摘要（英文原文）</summary>

Agent environments are essential for large language model (LLM) development. They use programmatic verifiers to turn complex outcomes into rewards. Verifiers can be attacked into awarding full credit to cheating agents without completing the intended task, causing inaccurate evaluation and misalignment in training. As agent environments scale in numbers and difficulty, so must the repairing of exploitable verifiers. To this end, we ask whether today's model with scaled compute can automatically harden agent environments to prevent potentially stronger future models from reward hacking. We introduce a scalable, fully automatic approach to weak-to-strong verifier hardening. It first sets up an isolated verifier sandbox that agents cannot directly modify, then uses a hacker-fixer loop to find and repair remaining verifier vulnerabilities. We apply this loop to Terminal Bench, KernelBench, and SETA, substantially reducing attack success across these agent environments. The iterative design scales with the hardening budget, producing progressively stronger defenses as the number of loop iterations increases and outperforming the static, non-iterative baseline.
