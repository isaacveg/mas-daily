# 多智能体系统论文日报（公开站点）

arXiv 上多智能体系统 / LLM 智能体（MAS / LLM-Agent）方向的每日论文日报。

- **在线站点**：<https://isaacveg.github.io/mas-daily/>
- **每日一期的 Markdown 原文**：[`daily/`](daily/)
- **图片资源**：[`assets/`](assets/)

## 筛选口径

1. 抓取 arXiv `cs.MA / cs.AI / cs.CL / cs.LG / cs.SE / cs.RO` 最新投稿；
2. 主题相关性过滤（多智能体、LLM 智能体、multi-robot 等关键词）；
3. 从论文 HTML 正文抽取作者机构归属，**只保留能识别出明确 T0/T1 机构的论文**
   （T0 = 顶级高校与头部 AI 实验室；T1 = 其他知名高校与工业研究院）；
4. 摘要统一译成中文（附英文原文折叠备查）；
5. 每篇挑选约 2 张图，优先「架构图 + 结果图」。

## 说明

本站内容由本地脚本 `每日调查/scripts/publish_site.py` 自动同步发布，
`index.md` / `daily/` / `assets/` 每次发布都会被覆盖，请勿手工修改。

论文版权归原作者所有，此处仅摘录标题、摘要与少量插图用于学术速览，并保留 arXiv 原文链接。
